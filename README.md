# MBTI Test Website

一个可在线访问的 MBTI 性格测试网站，包含：

- 快速版测试
- 专业版测试
- 结果页展示
- 16 型人格详情页
- GitHub Pages 部署

## 文件结构

- `index.html`：首页
- `quiz.html`：测试页
- `result.html`：结果页
- `styles.css`：全站公共样式
- `types/`：16 型人格详情页
- `results/`：结果数据
- `js/`：前端逻辑脚本

## 本地预览

直接用 VS Code Live Server 打开，或使用任意静态服务器预览。

## 部署

当前使用 GitHub Pages 部署。
